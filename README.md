# RioCruses_Santuario
El Santuario de la Naturaleza Carlos Anwandter (Río Cruces) es el primer sitio RAMSAR de Chile (declarado en 1981) y un humedal de extraordinaria riqueza biológica ubicado al norte de Valdivia.  Este santuario alberga una biodiversidad excepcional. Destaca principalmente como refugio para el cisne de cuello negro, especie emblemática de la zona
